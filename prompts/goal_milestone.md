# Chạy milestone

- Danh sách milestone và câu lệnh: `prompts/goals/README.md`.
- Mỗi milestone: copy dòng `/goal` ở đầu file `prompts/goals/Gxx_*.md` vào session Claude Code chính.
- Quy tắc chung cho mọi goal: `prompts/goal_protocol.md`.
- Tutor chạy ở terminal riêng: `claude --agent tutor` (xem `prompts/tutor_session.md`).
